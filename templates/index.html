      About this project

      What it does

      Sentinel classifies a job posting as likely legitimate or fraudulent using a supervised machine-learning model trained on the EMSCAD dataset of 17,880 real-world job listings (866 confirmed fraudulent).

      Pipeline

      1. Clean & normalize text (title, company profile, description, requirements, benefits)
      2. Engineer structured features (employment type, experience, education, industry, function, logo/remote/questions flags)
      3. Vectorize text with TF-IDF (unigrams + bigrams)
      4. Combine text + structured features into one feature matrix
      5. Train & compare 5 classifiers: Logistic Regression, Naive Bayes, Random Forest, Linear SVM, Gradient Boosting
      6. Select the best model by F1-score; serve it behind a Flask REST API

      Try it on a real listing

      Paste a link from LinkedIn, Indeed, Naukri, or a company careers page in the Analyze tab. Sentinel reads the page's structured job-posting data (the same schema.org markup Google Jobs uses) to auto-fill the form — no manual copy-paste needed. If a site blocks automated access, you can always fall back to pasting the details by hand.

      Limitations

      This is a statistical pattern-matcher trained on historical data, not a guarantee. Always independently verify an employer's official website, domain, and contact details before sharing personal information or applying.

      Browser Extension

      Scan a job posting without leaving LinkedIn, Indeed, or Naukri. The extension reads the page you're already viewing (logged in, fully rendered) and sends it here — the same read the site itself blocks for a logged-out server-side fetch.

      1. Load the extension/ folder from the project via chrome://extensions → Developer mode → Load unpacked
      2. Click the Sentinel icon in your toolbar and paste the API token below
      3. Open a job posting and click "Scan with Sentinel"
